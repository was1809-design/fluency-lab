# Fluency Lab

PWA adaptativo para aprender inglês com prática de fala, escrita e escuta.

## Recursos

- Treinos que priorizam a habilidade com menor desempenho
- Reconhecimento de voz e reprodução de pronúncia em inglês
- Correção imediata e revisão automática de erros
- XP, sequência, níveis e acompanhamento de progresso
- Instalação como PWA e funcionamento offline
- Layout responsivo para celular e computador
